## 前提
- 私はコードを読めない。動作の確認は、私が画面で見て判断できる手順にして出すこと。
- Effect House はGUIアプリなので、あなたは操作できない。画面操作は私がやる。あなたは下の「あなたの仕事」だけを担当する。
- 返答は日本語で、結論から。質問は一度に1つだけ。確認できていないことは「未確認」と書き、推測で断定しない。

## 守ること
- ソフトのインストール(Homebrew、npm の global インストール等)は、必ず先に私に聞く。標準で入っているもの(python3、sips、git など)で済ませる。
- ファイルを削除しない。作り直すときは別名で作る。
- 公開リポジトリなので、私の名前・メールアドレス・アカウント名・端末の識別情報・セッションのURLをファイルにもコミットメッセージにも書かない。
- 1ファイル300行以内。
- git push は、私が許可したときだけ。

## あなたの仕事

### 1. 環境の確認(すぐやる)
- macOS のバージョン、チップ(Apple Silicon か Intel か)、メモリ、空きディスク容量を調べて、表で報告する。
- `/Applications` に Effect House が入っているか確認する。
- リポジトリを `~/dev/summon-gacha-camera` に clone する(すでにあれば `git pull`)。
- Effect House の動作条件を公式ページで確認できたら、この Mac が満たすか判定する。確認できなければ「未確認」とする。
- 公式のダウンロードページの URL を調べ、確かに TikTok 公式(effecthouse.tiktok.com)であることを確認してから、`open` でブラウザに開く。インストーラーを curl で直接落とさない。

### 2. 試作用の素材画像を作る(S2〜S4 用)
`effect-house/assets/` に、次の PNG を作る。どれも 1MB 未満(Effect House の画像の上限)。
- `bg_dark.png`: 1080x1920、紺から紫の縦グラデーション(背景差し替え用)
- `result_ssr.png`: 透過背景に金色の大きな「SSR」
- `result_miss.png`: 透過背景に灰色の大きな「ハズレ」
- `particle_soft.png`: 128x128、中心が白く外側が透明になる丸(パーティクル用)
作ったら、ファイルサイズを一覧で報告し、`open` で画像を開いて私に見せる。

### 3. 抽選ロジックの移植(私が S3 で頼んだら)
- `src/config/gacha.ts`(排出表)と `src/logic/gacha.ts`(抽選)を、Effect House のスクリプトに移す。
- Effect House のスクリプト API は推測で書かない。私が作った Effect House プロジェクトのフォルダから、型定義(.d.ts)やサンプルのスクリプトを探して、それに合わせる。見つからなければ止まって報告する。
- 移植したスクリプトは `effect-house/scripts/` に置き、Effect House のどこに入れるかを手順で説明する。

### 4. 結果の記録(各ステップの後)
- 私が報告した結果(FPS、できた/できなかった、スクリーンショットの内容)を、`docs/effect-house-port.md` の該当ステップに書き、チェックボックスを更新する。
- ローカルで commit する。push は私の許可を待つ。
