# 召喚ガチャカメラ

スマホのカメラに映った自分に、ガチャ形式で召喚エフェクトがかかる Web プロトタイプ。
最終目標は TikTok Effect House での公開。まずブラウザで面白さと排出バランスを検証する。

- 公開リポジトリ。個人情報・認証情報は絶対に入れない
- 開発: `npm install` → `npm run dev`(HTTPS、LAN から開ける)
- テスト: `npm test` / ビルド: `npm run build`
- 配信: `main` への push で GitHub Pages に自動デプロイ

## 状態: 凍結(2026-10-19)

Web 版は「排出バランスと演出の間の検証用」として、この時点で作り込みを止めた。
本番は TikTok Effect House で作る(方針と調査は `docs/effect-house-port.md`)。

- できていること: 抽選・予告色・状態遷移、人物の切り抜き、演出12種(仮素材)、隠しポーズ(広画角モード)、デバッグパネル(`?debug=1`)
- 作らないこと: 演出の見た目の作り込み(Effect House では作り直しになるため)
