# 召喚ガチャカメラ

スマホのカメラに映った自分に、ガチャ形式で召喚エフェクトがかかる Web プロトタイプ。
最終目標は TikTok Effect House での公開。まずブラウザで面白さと排出バランスを検証する。

- 公開リポジトリ。個人情報・認証情報は絶対に入れない
- 開発: `npm install` → `npm run dev`(HTTPS、LAN から開ける)
- テスト: `npm test` / ビルド: `npm run build`
- 配信: `main` への push で GitHub Pages に自動デプロイ

現状: カメラ表示と FPS 表示のみ(実機での FPS は未確認)。
